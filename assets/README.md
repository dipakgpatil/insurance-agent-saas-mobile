# Assets

Placeholder folder. Replace these files with real artwork before publishing:

- `icon.png` — 1024×1024 app icon
- `splash.png` — 1242×2436 splash image (or any portrait size; Expo letterboxes)
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground

For an initial build you can generate temporary assets with:

```
npx expo install expo-asset
npx create-expo-icon
```

Or use Expo's online tools at https://docs.expo.dev/develop/user-interface/splash-screen/.
